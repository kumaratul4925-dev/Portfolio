# Atul Kumar — HTML/CSS/JavaScript/Bootstrap Portfolio

## Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Run
No build tools are required.

Simply open `index.html` in your browser.

For best development experience, open the folder in VS Code and use Live Server.

## Important customization
Open `index.html` and replace:
- `your-email@example.com`
- LinkedIn URL
- GitHub URL
- Project GitHub/live-demo links
- Project descriptions if needed

You can also add your resume as `assets/Atul-Kumar-Resume.pdf` and add a Resume button in the navbar/hero.

## Note
Bootstrap is loaded from jsDelivr CDN, so an internet connection is needed for Bootstrap styling/icons unless you download Bootstrap locally.
